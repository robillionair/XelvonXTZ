     GOOD TO KNOW
    Simple answers.
    
      
    Do you upload or store my files?＋
    No. The compiler reads selected files inside this browser tab. Only the email you enter after compilation is sent to Robillionair.
    What files can I use?＋
    Plain Markdown and text files: .md, .markdown and .txt. Select up to 100 files, with a 20 MB combined limit.
    How are duplicates removed?＋
    ANANSI normalizes formatting and compares meaningful words. Exact repeats and highly similar points are combined while source filenames are kept.
    Will an AI remember the file forever?＋
    Not automatically. The file supplies context for the chat or project where you attach it. Permanent memory depends on that AI product.
